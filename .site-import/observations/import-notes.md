# Website importer — repository adaptation
Source: https://github.com/YashDrall19/Portfolio_GOT.git (main)
The supplied URL is a source repository, not a hosted website. Imported source directly rather than capturing the GitHub repository page. Reference rendered from the original SPA with its original Tailwind v3 stylesheet.

Verified desktop (1280 × 1800) and phone (390 × 844): all six content sections, original castle photograph, hero work link, phone menu Work link, theme and sound toggles, footer return link. Contact submission succeeded on preview. Original contact service is unconfigured in the supplied repository.

No video, nested menus, accordion, carousel, or popup is present in the source. Hero uses the original CSS 3D sigil (not a canvas replacement); original pointer and scroll effects remain. Tailwind v4 separates translation from transforms, so sigil positioning is centered instead of reproducing the original transform override. No static media fallback or normal-flow panel substitution was introduced.

Source hero name was invisible through a transparent gradient inherited by animated character spans. Preview fixes this with the source accent color. Test contact messages are explicitly labelled Portfolio import verification.
